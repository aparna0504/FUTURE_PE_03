# Prompts Used

## 0. Reusable Template
```
ROLE: You are an SEO content strategist and editor for local business websites.
BUSINESS: [name, services, city]
AUDIENCE: [who, what they're trying to do]
PRIMARY KEYWORD: [one]  SECONDARY: [3–5]  SEARCH INTENT: [informational / commercial / local]
TASK: [deliverable]
CONSTRAINTS: Answer the query in the first 100 words · natural keyword use (no stuffing) · short paragraphs · helpful before promotional · no invented statistics · include a clear CTA at the end
FORMAT: [H1–H3 outline / ~1,000-word post / meta title + description]
```

## 1. Keyword & Intent Mapping
```
Maple & Main Café, Portland OR. Suggest 20 search phrases our audience would use. Classify each as informational, commercial, or local-transactional. Group into 1 pillar topic + 4 supporting topics. Flag that volumes must be verified with a keyword tool.
```

## 2. Outline Prompt
```
For each of the 5 topics, write an SEO outline: H1 (with primary keyword), meta title (≤60 chars), meta description (≤155 chars), H2s and H3s matching search intent, an FAQ block (3 questions), and suggested internal links.
```

## 3. Long-Form Draft Prompt
```
Write the pillar post (~1,000 words) from the outline. Start with a direct answer. Be genuinely useful: practical tips, specifics, honest recommendations. Mention Maple & Main naturally, no more than 3 times. End with a CTA. Use [PLACEHOLDER] for facts I must confirm.
```

## 4. Internal Linking Prompt
```
Create an internal linking map: which post links to which, with suggested anchor text (varied, descriptive, not exact-match every time). Pillar links to all four; each supporting post links back to the pillar and to one sibling.
```

## 5. Local SEO Prompt
```
Adapt the post for local search: add Portland neighborhood references, "near me" style phrasing used naturally, a service-area section, and a LocalBusiness-friendly FAQ. Do not invent landmarks, distances, or reviews.
```
